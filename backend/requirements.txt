# ── Intel-mac wheel reality (env markers, evaluated per interpreter) ──────
# The mac x64 sidecar (release.yml pass-2, Rosetta, Python 3.12) and real
# Intel Macs must resolve a DIFFERENT, older wheel set than arm64/linux/win:
#   mediapipe   — upstream NEVER shipped an Intel-mac cp313 wheel; Intel
#                 support ended at 0.10.21 (cp312 max). It also requires
#                 numpy<2, and opencv 5.x requires numpy>=2 → opencv is
#                 capped at 4.x in this environment.
#   onnxruntime — x86_64-mac wheels end at 1.23.2 (1.24+ is arm64-only).
# `platform_machine` reports x86_64 under Rosetta translation, so the same
# file serves pass-1 (arm64 → modern pins) and pass-2 (x64 → legacy pins).
